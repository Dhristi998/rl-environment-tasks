# RL environment tasks: legacy-code ports and outcome-driven tasks

Four Terminal-Bench-style tasks for training and evaluating coding agents, packaged in the
[Harbor](https://pypi.org/project/harbor/) task format. Each task has a Docker environment, an
instruction for the agent, a reference solution, and a verifier that scores the agent's work
with a reward of 1 or 0.

| Task | Kind | What the agent must do | Difficulty |
|---|---|---|---|
| `fortran-amortization-port` | Language-driven | Port a Fortran 77 loan-amortisation program to Python with byte-identical output | Medium |
| `cobol-sales-report-port` | Language-driven | Port a GnuCOBOL control-break sales report (edited pictures like `ZZZ,ZZZ,ZZ9.99`) to Python | Hard |
| `inventory-reconciliation` | Outcome-driven | Build a CLI that reconciles messy order and return exports into net units per product | Medium |
| `rate-limiter-fix` | Outcome-driven | Make a failing token-bucket test suite pass without touching the tests | Easy |

## Task layout (Harbor format)

```
tasks/<task>/
├── task.toml              # metadata, timeouts, separate verifier, /app collected as an artifact
├── instruction.md         # what the agent sees
├── environment/
│   ├── Dockerfile         # the agent's sandbox (ubuntu:24.04 + gfortran / gnucobol4 / python3)
│   └── app/               # starting files copied to /app
├── solution/solve.sh      # reference (oracle) solution
└── tests/
    ├── test.sh            # runs the verifier and writes /logs/verifier/reward.txt
    └── test_outputs.py    # hidden tests
```

## How the verifiers resist shortcuts

- **Fresh hidden inputs on every run.** The tests generate random loans, sales files and CSV exports
  with a seed from `os.urandom`, so hard-coding the answer for the sample file scores 0.
- **Ground truth checked against the real legacy program.** `scripts/validate.py` compiles the
  original Fortran and COBOL and checks that the reference answer matches them on 200 random
  inputs, so the verifier is grading against real legacy behaviour.
- **Edge cases the instructions don't spell out.** Zero-interest loans, a last month that absorbs
  rounding, unsorted COBOL input (a region can appear in several blocks), returns for unknown
  orders, and returns larger than the order.
- **Protected files.** The rate-limiter verifier checks the SHA-256 of the visible test file, and
  the port verifiers reject solutions that import `subprocess` or `ctypes` or call the legacy
  compiler.
- **Separate verifier container.** `environment_mode = "separate"`: Harbor copies the agent's
  `/app` into a fresh container before running the tests, so the agent cannot tamper with them.

## Validation

`scripts/validate.py` runs three agents on every task without needing Docker:

- **null agent:** does nothing. Must score 0.
- **oracle agent:** runs `solution/solve.sh`. Must score 1.
- **shortcut agent:** a cheat in `scripts/shortcut_agents/`. It hard-codes the sample answer or
  edits the tests, passing the visible checks. Must score 0.

```
$ python3 scripts/validate.py
PASS  cobol-sales-report-port          null=0  oracle=1  shortcut=0
      legacy check: matches legacy COBOL on 200 random inputs
PASS  fortran-amortization-port        null=0  oracle=1  shortcut=0
      legacy check: matches legacy Fortran on 200 random inputs
PASS  inventory-reconciliation         null=0  oracle=1  shortcut=0
PASS  rate-limiter-fix                 null=0  oracle=1  shortcut=0
```

`harbor lint tasks/*` reports no findings.

## Running with Harbor and Docker

```bash
pip install harbor
harbor lint tasks/*
harbor run -p tasks/fortran-amortization-port -a oracle      # should score 1
harbor run -p tasks/fortran-amortization-port -a nop         # should score 0
harbor run -p tasks/fortran-amortization-port -a claude-code -m <model>   # a real agent run
```

Legacy-check requirements for `validate.py`: `gfortran` and `cobc` (GnuCOBOL) on your PATH.
Without them, those checks are skipped.

## Regenerating the tasks

All task files are generated by `make_repo.py`. After editing it, run it again and refresh the
rate-limiter test hash:

```bash
python3 make_repo.py
SHA=$(sha256sum tasks/rate-limiter-fix/environment/app/ratelimiter/tests/test_ratelimiter.py | cut -d' ' -f1)
sed -i "s/__VISIBLE_SHA__/$SHA/" tasks/rate-limiter-fix/tests/test_outputs.py
python3 scripts/validate.py
```
